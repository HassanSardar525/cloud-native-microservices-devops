🔔 Notification Service

Notifications

Delivers email and in-app alerts triggered by order and system events.

📧

POST /notify/email

Send an email notification via SMTP to a registered user address.

🔔

POST /notify/inapp

Push an in-app notification to the user's notification feed.

📋

GET /notifications/:userId

Fetch all notifications for a user, sorted by timestamp.

✅

PATCH /notifications/:id/read

Mark a notification as read and update the unread counter.
