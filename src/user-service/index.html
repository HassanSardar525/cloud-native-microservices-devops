👤 User Service

User Management

Handles registration, login, JWT authentication, and user profiles.

🔐

POST /auth/register

Create a new user account with hashed password and email verification.

🗝️

POST /auth/login

Authenticate user and return a signed JWT access token.

📋

GET /users/:id

Fetch user profile. Requires valid JWT in Authorization header.

✏️

PUT /users/:id

Update user profile fields including name, email, and preferences.
